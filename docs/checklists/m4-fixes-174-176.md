# M4 fixes 174 to 176: checklist for Inventor

Branch `claude/m4-hole-table` (PR #32). Close Inventor, run `dotnet build InventorAddin.slnx`, check the deploy line, start Inventor. Log: `%APPDATA%\AwbAddin\awbaddin.log`. The full steps are in each task file's Verification section.

## 174: a selected sketch point picks itself and the free hole centres

1. Part with one sketch of 5 hole-centre points; make a hole on 2 of them.
2. Click a free point, then AWB Hole on its mini toolbar: the 3 free points are picked, not the 2 used ones.
3. Select a used point, start AWB Hole: that point and the 3 free ones (4).
4. Ctrl-select one used and one free point: both, plus the other free points.
5. Make the other 3 holes so every point is used; select one point and start AWB Hole: all 5.
6. Selecting a sketch (not a point) behaves as before: its free centres, or all when all are used.

## 176: automatic hole table check (uses 175)

Use a drawing with hole tables made by the Hole Table wizard. Settings, Holes: "Check hole tables when a drawing opens or updates" is ticked (default).

1. Open the drawing with nothing changed and wait 3 s: no window. The log has `Hole table check: NAME.idw, no views out of date`. If it shows only `Hole table check: waiting, ...` lines, send me their text.
2. In the part, move or add a hole, save, go back to the drawing: about 2 s later a small window lists the view and why, with Update now and Later.
3. Change the part again while the part stays active: no window until you switch to the drawing.
4. Later, switch away and back: no window. Change the part again: the window comes back.
5. Update now with two out-of-date views: the tables redraw; each Undo reverts one view.
6. Open the Hole Table wizard on an out-of-date drawing: only the wizard's own message, no second window. Close it: no prompt.
7. Untick the setting, Save, repeat step 2: no window, no `Hole table check` lines.
8. A saved drawing with nothing out of date: after the check, no new Undo entry and no save prompt on close.
9. Start a dimension or sketch command right after the drawing updates: the window waits until the command ends.
