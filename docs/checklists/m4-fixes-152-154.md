# Inventor check: fixes 152 to 154

The fixes from Aidan's 140 to 150 check (2026-11-10). Built on Windows (0 errors) and deployed; nothing here has run in Inventor. Just start Inventor; the Built time in About should be today's. Logs are in `%APPDATA%\AwbAddin\awbaddin.log`.

## 152: New faces take the bore's colour when a hole is changed in place (140-2)

1. A blind clearance hole, no seat, only its bore coloured by hand. Edit it in AWB Hole and add a counterbore: the counterbore wall and floor turn the bore's colour in the preview. The existing drill point stays as it was. OK. The log has "N new face(s) of M on HoleX took the bore's hand colour after the change in place".
2. One Undo: back to no seat, only the bore coloured.
3. Edit again: add a counterbore, set the seat to none, add it again, OK: the wall and floor are in the bore's colour. Try a countersink and a spotface too.
4. A through clearance hole with its bore coloured: make it blind (Distance). The new drill point (or flat bottom) takes the bore's colour.
5. A counterbored hole with its wall red and bore blue: change only the diameter. The colours stay as they were, and the log reports 0 new faces.

## 153: Flat Pattern uses Inventor's Hole everywhere

1. A sheet metal part, Flat Pattern: press H. Inventor's Hole opens and stays open. The log has "a flat pattern is being edited, so Inventor's Hole runs instead" and no "AWB Hole opens instead".
2. Still in the Flat Pattern: double-click a hole in the browser and on one of its faces, and use Edit Feature (right-click and mini toolbar): Inventor's own hole edit opens each time.
3. Go to Folded Part: H, double-click and Edit Feature open AWB Hole as before. A plain part is unchanged.
4. Note: the AWB Hole button on the AWB Addin tab also opens Inventor's Hole in a flat pattern.

## 154: A sketch picks its free hole centres (145-3, 117-4)

Set up: Sketch A with 5 hole-centre points, an Inventor Hole on 2 of them; Sketch B with 2 unused points.

1. Select Sketch A in the browser, then AWB Hole: its 3 free points are picked; the log says "selected, 3 free of 5 hole centres".
2. With the window open, click Sketch B, then Sketch A in the browser: B gives 2; A gives its 3 free points again, **not 5**. (If it gives 5, send the log: the preview hole was counted as using them.)
3. Click one of A's used points in the model: it is added.
4. Cancel. Put a hole on A's other 3 points too. Click A in the browser with the window open, and select A before opening AWB Hole: all 5 are picked each time ("all ... are used, so all are picked").
5. Select one point of Sketch A (not the sketch), then AWB Hole: all 5 of A's centres are picked, as before.
