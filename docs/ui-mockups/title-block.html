AWB title block: mockup for comment

One title block, 180 by 50 mm, the same on every sheet size (ISO A4 to A0, ANSI A to E). White sheet, third angle projection. Every value is read from the model's properties, so the print changes when the model does. All values below are made up.

Drawn at about 7 times full size. Yellow numbers match the table below. Labels 1.8 mm, values 3.5 mm, part number and revision 5 mm, text in Tahoma (Inventor's drawing font).

On the sheet

A3 landscape. Border 20 mm on the left (filing edge), 10 mm elsewhere. The finish notes block (answer 11) sits on the title block; the views are placeholders.
A4 portrait: the 180 mm block fills the width inside the border exactly. ANSI A portrait has 190 mm inside its 0.5 in border, so it fits there too.

Questions for you

  1. Logo: the black mark (shown), or the round sage logo? The sage one prints grey on a black and white printer.
  2. General tolerances: what wording? Shown: mm X ±0.5, X.X ±0.2, X.XX ±0.05, angles ±0.5°; inches .X ±.030, .XX ±.010, .XXX ±.005, angles ±0.5°. Or a standard reference such as ISO 2768-m.
  3. Status: a custom "Status" property, or Inventor's built-in Design Status (Work in progress, Pending, Released)? The built-in one is what Vault uses, which may matter for the PDM later.
  4. Detailer: the model's custom Detailer (written by New Part today), or the drawing's own Author?
  5. Date: the model's creation date, the drawing's creation date, or a date property you set by hand (for example on release)?
  6. Size: keep the Size field (17), or drop it?
  7. Layout: anything to move, resize or regroup?
