AWB title block: template additions for approval

One title block, 180 mm wide, the same on every sheet size (ISO A4 to A0, ANSI A to E). White sheet, third angle projection. Every value is read from the model or the drawing, so the print changes when they do. All values below are made up. The 50 mm block is as approved on 2026-11-21. New in this round (blue numbers): a full-width FINISH line directly above the block for the long finish callout, a row of small fields above it (project and file name), a Material Size field, the part number repeated small in the right margin, and on the sheet the zone grid with centring arrows and an X/Y triad. The block with the two new rows is 180 by 62 mm.

Metric, drawn at about 6.5 times full size. Labels 1.8 mm, values 2.8 mm (project, file name and material size 2.5 mm), description 4 mm, part number and revision 7 mm bold, status 2.5 mm. The part number in the right margin is 2.5 mm, read from the bottom, and sits outside the border. Text in Tahoma (Inventor's drawing font).

Imperial

Only the tolerance box (2), the units, the weight's unit, the material size's unit and the size differ. Both tolerance boxes carry the "UNLESS OTHERWISE SPECIFIED:" heading.

On the sheet

A3 landscape, 8 by 6 zones. Border 20 mm on the left (filing edge), 10 mm elsewhere. The views are placeholders. The NOTES list and the bold "NOTE: 3D PRINTED PART" line come from the automatic notes command (examples, not in the template).
A4 portrait, 4 by 6 zones: the 180 mm block fills the width inside the border exactly. ANSI A portrait has 190 mm inside its 0.5 in border, so it fits there too.
